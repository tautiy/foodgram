## Описание проекта

**Foodgram** — это веб-приложение, где пользователи могут публиковать рецепты, добавлять их в избранное, формировать список покупок и подписываться на авторов.

Проект написан на **Django + DRF**, фронтенд на **React**, база данных — **PostgreSQL**. Развёрнут в **Docker** контейнерах.
